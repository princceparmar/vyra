# VYRA Microservice — Product Service

This microservice independently manages **Product Catalogue, Categories, Search, Filters, and Inventory Stock**.

## Compulsory Academic Requirement Verification
- **GUI**: Dedicated standalone web interface served at `http://localhost:8012/`
- **Business Logic**: Product retrieval, stock validation, multi-criteria filtering
- **Database**: Dedicated SQLite database `database/products.db`

## Port
- API & GUI: `http://localhost:8012`
