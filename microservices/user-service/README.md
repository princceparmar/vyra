# VYRA Microservice — User Service

This microservice independently manages **User Registration, Login, Authentication, and User Profiles**.

## Compulsory Academic Requirement Verification
- **GUI**: Dedicated standalone web interface served at `http://localhost:8011/`
- **Business Logic**: FastAPI routes handling authentication & input validation
- **Database**: Dedicated SQLite database `database/users.db`

## Port
- API & GUI: `http://localhost:8011`
