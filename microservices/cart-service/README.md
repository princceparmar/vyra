# VYRA Microservice — Cart & Wishlist Service

This microservice independently manages **Shopping Cart items, Quantity Validation, Wishlist Storage, and Discount Calculations**.

## Compulsory Academic Requirement Verification
- **GUI**: Dedicated standalone web interface served at `http://localhost:8013/`
- **Business Logic**: Cart total calculation algorithms, discounts, item updates
- **Database**: Dedicated SQLite database `database/cart.db`

## Port
- API & GUI: `http://localhost:8013`
