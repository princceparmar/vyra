# VYRA Microservice — Payment Service

This microservice independently manages **Simulated Payment Gateway Processing (UPI, Credit Card, COD), Payment Failure Simulation, and Transaction Logs**.

## Compulsory Academic Requirement Verification
- **GUI**: Dedicated standalone web interface served at `http://localhost:8015/`
- **Business Logic**: Payment authorization validation, failure simulation, audit log recording
- **Database**: Dedicated SQLite database `database/payments.db`

## Port
- API & GUI: `http://localhost:8015`
