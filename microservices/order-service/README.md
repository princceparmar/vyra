# VYRA Microservice — Order Service

This microservice independently manages **Order Creation, Order History, Item Tracking, and Status Updates**.

## Compulsory Academic Requirement Verification
- **GUI**: Dedicated standalone web interface served at `http://localhost:8014/`
- **Business Logic**: Order generation, status progression timeline, historical query processing
- **Database**: Dedicated SQLite database `database/orders.db`

## Port
- API & GUI: `http://localhost:8014`
